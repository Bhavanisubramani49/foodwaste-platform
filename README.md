# FoodWasteAI — AI-Powered Food Waste Management Platform

## About the Project
FoodWasteAI is a web application designed to reduce food waste by connecting restaurants, supermarkets, and other food providers with NGOs and community kitchens.

The platform supports inventory tracking, expiry alerts, waste-risk analysis, surplus food redistribution, and impact monitoring.

## Key Features
- Inventory management and expiry tracking
- Expiry and low-stock alerts
- AI-based waste-risk scoring
- Surplus food listings and NGO matching
- Donation request and pickup tracking
- Food recovery and impact analytics

## Technology Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Database:** PostgreSQL
- **Data Analysis / AI:** Pandas, Scikit-learn
- **Charts:** Chart.js

## Project Milestones
- **Milestone 1:** Inventory management and expiry tracking
- **Milestone 2:** AI-based waste prediction
- **Milestone 3:** NGO marketplace and analytics dashboard
- **Final Phase:** Integration, testing, and documentation

## Project Status
Development is in progress. Features are being implemented and tested incrementally.

## Run Locally
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure the required environment variables in `.env`.
5. Run database migrations using `python manage.py migrate`.
6. Start the development server using `python manage.py runserver`.

Never commit real database credentials or secret keys.
